# Système d'information d'usine

> Une application web de gestion d'usine, réalisée pour le cours « Projet Agile des Logiciels » à l'ESATIC (Licence TWIN).

## Le projet

Une application Django pour gérer le système d'information d'une usine, développée en binôme selon la méthode Scrum.

## Méthode

- Travail en **sprints Scrum**
- Backlog et sprints suivis sur **YouTrack**
- Rapport de projet rédigé en fin de parcours

## Technologies

| Rôle | Technologie |
| --- | --- |
| Langage | Python |
| Framework | Django |
| Gestion de projet | Scrum, YouTrack |
